*** Read the context file. Propose refraction and revisions.

Here’s a focused review of =src/network.py=, with a refactor plan and concrete revisions.

**** High-level assessment

The file works as a monolithic simulation/training engine, but it mixes:

- configuration loading
- parameter/state initialization
- connectivity construction
- training-time weight composition
- dynamical simulation
- STP / Hebbian / adaptation logic
- stateful episodic carry-over

This makes it harder to:
- reason about tensor shapes
- test individual mechanisms
- maintain correctness across many flags
- avoid silent bugs from state mutation

The main issues are:
1. *Too much mutable state on =self=*
2. *Flag-driven branching everywhere*
3. *Inconsistent tensor ownership* (=Wab_T=, =Wab_train=, =W_stp_T=, Hebbian-expanded =Wab_T=)
4. *State initialization and persistence logic intertwined with forward*
5. *Potential bugs around device moves, in-place ops, shape assumptions*
6. *Sparse import is unused*
7. *Naming/transposition semantics are hard to follow*

*** Refactor proposal

**** 1. Separate persistent model parameters from transient dynamical state

Right now =self= stores both:
- fixed model parameters: =Wab_T=, masks, low-rank module, config
- transient simulation state: =rates_last=, =rec_input_last=, =hebb_rates_last=, =u_stp_last=, etc.

***** Proposed split

Introduce a simulation state container, e.g.:

#+begin_src python

@dataclass

    rates: torch.Tensor
    rec_input: torch.Tensor
    thresh: torch.Tensor
    ff_prev: torch.Tensor | int
    hebb_rates: torch.Tensor | None = None
    u_stp_last: list | None = None
    x_stp_last: list | None = None
    u_ff_stp_last: torch.Tensor | None = None
    x_ff_stp_last: torch.Tensor | None = None
#+end_src

Then:
- =init_state(ff_input)= returns a =NetworkState=
- =step(state, ff_step, weights)= returns updated =state=
- =forward()= becomes orchestration only

This is the single biggest improvement.

Currently =forward()= builds effective weights using:
- base connectivity

- EI mask
- STP decomposition

def recurrent_matmul(rates: torch.Tensor, W: torch.Tensor) -> torch.Tensor:
    """
    rates: (B, N)
    W:     (N, M) or (B, N, M)
    out:   (B, M)

    Convention:
        W[pre, post], so rates @ W gives postsynaptic input.
    """
    if W.dim() == 2:
        return rates @ W
    if W.dim() == 3:
        return torch.bmm(rates.unsqueeze(1), W).squeeze(1)
    raise ValueError(f"Unsupported shapes: rates={rates.shape}, W={W.shape}")

class Network(nn.Module):
    """
    Refactored recurrent rate network skeleton.

    Design goals:
    - keep persistent parameters/buffers separate from transient state
    - keep weight construction separate from step dynamics
    - keep forward() focused on orchestration
    """

    def __init__(self, conf_name, repo_root, **kwargs):
        super().__init__()

        self.config = Configuration(conf_name, repo_root)(**kwargs)
        self._load_config(self.config)

        self.activation = Activation()

        self._init_base_weights()
        self._init_trainable_weights()
        self._init_optional_modules()

        set_seed(-1)
        clear_cache()

    # ------------------------------------------------------------------
    # Configuration / initialization
    # ------------------------------------------------------------------

    def _load_config(self, config):
        for key, value in vars(config).items():
            if hasattr(self, key):
                raise ValueError(f"Config key collision with Network attribute: {key}")
            setattr(self, key, value)

    def _init_base_weights(self):
        """
        Build fixed recurrent matrix in computation orientation:
            W_rec[pre, post]
        """
        W_rec = torch.zeros((self.N_NEURON, self.N_NEURON), device=self.device)

        for post in range(self.N_POP):
            for pre in range(self.N_POP):
                conn = Connectivity(
                    self.Na[post],
                    self.Na[pre],
                    self.Ka[pre],
                    device=self.device,
                )

                block = conn(
                    self.CON_TYPE,
                    self.PROBA_TYPE[post][pre],
                    kappa=self.KAPPA[post][pre],
                    phase=self.PHASE,
                    sigma=self.SIGMA[post][pre],
                    lr_mean=self.LR_MEAN,
                    lr_cov=self.LR_COV,
                    ksi=self.PHI0,
                )

                # block is assumed [post, pre]; store as [pre, post]
                W_rec[self.slices[pre], self.slices[post]] = self.Jab[post][pre] * block.T

        self.register_buffer("W_rec_base", W_rec)

    def _init_trainable_weights(self):
        if self.TRAIN_EI:
            train_shape = (self.N_NEURON, self.N_NEURON)
        else:
            train_shape = (self.Na[0], self.Na[0])

        self.W_train_dense = None

        if not self.LR_TRAIN:
            self.W_train_dense = nn.Parameter(
                torch.randn(train_shape, device=self.device) * self.LR_INI
            )

        if self.TRAIN_EI:
            mask = torch.zeros(train_shape, device=self.device)
            for post in range(self.N_POP):
                for pre in range(self.N_POP):
                    mask[self.slices[pre], self.slices[post]] = self.IS_TRAIN[post][pre]
            self.register_buffer("train_mask", mask)
        else:
            self.train_mask = None

                N_NEURON=self.Na[0],
                RANK=self.RANK,
                LR_MN=self.LR_MN,
                LR_READOUT=self.LR_READOUT,
                LR_INI=self.LR_INI,
                LR_UeqV=self.LR_UeqV,
                DEVICE=self.device,
                LR_TYPE=self.LR_TYPE,
                LR_N_SUPPORTS=self.LR_N_SUPPORTS,
                LR_SUPPORT_WEIGHTS=self.LR_SUPPORT_WEIGHTS,
                LR_BASIS_DIM=self.LR_BASIS_DIM,
                LR_TRAIN_BIASES=self.LR_TRAIN_BIASES,
                LR_READOUT_DIM=self.LR_READOUT_DIM,
                LR_INIT_GAUSSIAN_BASIS=self.LR_INIT_GAUSSIAN_BASIS,
            )
        else:
            self.low_rank = None

        self._init_stp_buffers()
        self._init_ff_stp_buffers()

    def _init_stp_buffers(self):
        self.stp_block_index = []
        self.W_stp_blocks_base = []

        if not self.IF_STP:
            return

        J_stp = torch.tensor(self.J_STP, device=self.device, dtype=torch.float32)
        if getattr(self, "TRAIN_J_STP", False):
            self.J_STP_param = nn.Parameter(J_stp)
        else:
            self.register_buffer("J_STP_param", J_stp)

        for post in range(self.N_POP):
            post_slice = self.slices[post]
            for pre in range(self.N_POP):
                pre_slice = self.slices[pre]
                idx = pre + post * self.N_POP

                if self.IS_STP[idx]:
                    block = self.W_rec_base[pre_slice, post_slice].clone() / torch.abs(self.Jab[post, pre])
                    self.stp_block_index.append((pre, post, idx))
                    self.W_stp_blocks_base.append(block)

    def _init_ff_stp_buffers(self):
        # Placeholder for future persistent FF-STP module setup if needed
        pass

    # ------------------------------------------------------------------
    # State initialization / restoration
    # ------------------------------------------------------------------

    def init_ff_input(self):
        return init_ff_input(self)

    def _prepare_ff_input(self, ff_input: Optional[torch.Tensor]) -> torch.Tensor:
        if ff_input is None:
            if self.VERBOSE:
                print("Generating ff input")
            ff_input = init_ff_input(self)
        return ff_input.to(self.device)

    def initialize_state(self, ff_input: torch.Tensor) -> NetworkState:
        self.N_BATCH = ff_input.shape[0]

        thresh = self.thresh[: self.N_BATCH].clone()

        rec_input = torch.randn(
            (self.IF_NMDA + 1, self.N_BATCH, self.N_NEURON),
            device=self.device,
        )

        ff0 = ff_input if self.LIVE_FF_UPDATE else ff_input[:, 0]

        if self.IF_FF_ADAPT:
            self.thresh_ff = torch.zeros_like(ff_input[:, 0])

        rates = self.activation(ff0 + rec_input[0], func_name=self.TF_TYPE, thresh=thresh)

        hebb_rates = rates.clone() if self.IF_HEBB else None

        state = NetworkState(
            rates=rates,
            rec_input=rec_input,
            thresh=thresh,
            ff_prev=torch.zeros_like(ff0),
            hebb_rates=hebb_rates,
            u_stp_last=None,
            x_stp_last=None,
            u_ff_stp_last=None,
            x_ff_stp_last=None,
        )

        return state

    def restore_state(self) -> NetworkState:
        state = NetworkState(
            rates=self.rates_last,
            rec_input=self.rec_input_last,
            thresh=self.thresh_last,
            ff_prev=self.ff_prev_last,
            hebb_rates=getattr(self, "hebb_rates_last", None),
            u_stp_last=getattr(self, "u_stp_last", None),
            x_stp_last=getattr(self, "x_stp_last", None),
            u_ff_stp_last=getattr(self, "u_ff_stp_last", None),
            x_ff_stp_last=getattr(self, "x_ff_stp_last", None),
        )
        return state

    # ------------------------------------------------------------------
    # Weight construction
    # ------------------------------------------------------------------

    def build_trainable_matrix(self) -> Optional[torch.Tensor]:
        if self.LR_TRAIN:
            return self.low_rank(self.LR_NORM)
        return self.W_train_dense

    def build_effective_recurrent_weights(self) -> torch.Tensor:
        """
        Returns effective recurrent matrix before Hebbian expansion.
        Shape:
            (N, N)
        """
        W_rec = self.W_rec_base.clone()

        W_train = self.build_trainable_matrix()
        if W_train is None:
            return W_rec

        if self.TRAIN_EI:
            for pop_idx in range(self.N_POP):
                W_train = normalize_tensor(W_train, pop_idx, self.slices, self.train_scale)

            W_rec = W_rec + self.train_mask * W_train

            if self.CLAMP:
                for pop_idx in range(self.N_POP):
                    W_rec = clamp_tensor(W_rec.T, pop_idx, self.slices).T
        else:
            # E-to-E local training case
            W_rec[self.slices[0], self.slices[0]] = (
                W_rec[self.slices[0], self.slices[0]]
                + self.GAIN * W_train / torch.sqrt(self.Ka[0])
            )

            if self.CLAMP:
                W_rec = clamp_tensor(W_rec.T, 0, self.slices).T

        return W_rec

    def build_effective_stp_weights(self, W_train: Optional[torch.Tensor]) -> Optional[list]:
        if not self.IF_STP:
            return None

        W_stp = []
        J_stp = self.J_STP_param
        fix_scale = torch.sqrt(self.Ka[0])

        for k, (pre, post, idx) in enumerate(self.stp_block_index):
            base_block = self.W_stp_blocks_base[k]

            if pre == 0 and post == 0 and W_train is not None and not self.TRAIN_EI:
                block = (
                    self.GAIN
                    * J_stp
                    * (
                        base_block / fix_scale
                        * (1.0 + W_train[self.slices[0], self.slices[0]] / self.train_scale[0])
                    )
                )
                if self.CLAMP:
                    block = clamp_tensor(block, 0, self.slices)
            else:
                block = self.W_STP[idx] * J_stp * base_block / torch.sqrt(self.Ka[pre])

            W_stp.append(block)

        return W_stp

    def expand_weights_for_hebbian(self, W_rec: torch.Tensor) -> torch.Tensor:
        if not self.IF_HEBB:
            return W_rec
        return W_rec.unsqueeze(0).repeat(self.N_BATCH, 1, 1)

    # ------------------------------------------------------------------
    # Plasticity module construction
    # ------------------------------------------------------------------

    def make_stp_modules(self, state: NetworkState, reset_state: bool):
        if not self.IF_STP:
            return None

        stp_modules = []
        u_last = [] if reset_state else state.u_stp_last
        x_last = [] if reset_state else state.x_stp_last

        for pre, post, idx in self.stp_block_index:
            mod = Plasticity(
                self.USE[idx],
                self.TAU_FAC[idx],
                self.TAU_REC[idx],
                self.DT,
                (self.N_BATCH, self.Na[pre]),
                STP_TYPE=self.STP_TYPE,
                IF_INIT=reset_state,
                device=self.device,
            )

            if reset_state:
                u_last.append(torch.zeros_like(mod.u_stp.detach()))
                x_last.append(torch.zeros_like(mod.x_stp.detach()))
            else:
                mod.u_stp = u_last[len(stp_modules)].detach()
                mod.x_stp = x_last[len(stp_modules)].detach()

            stp_modules.append(mod)

        state.u_stp_last = u_last
        state.x_stp_last = x_last
        return stp_modules

    def make_ff_stp_module(self, state: NetworkState, reset_state: bool):
        if not self.IF_FF_STP:
            return None

        mod = Plasticity(
            self.FF_USE,
            self.TAU_FF_FAC,
            self.TAU_FF_REC,
            self.DT,
            (self.N_BATCH, self.N_NEURON),
            STP_TYPE=self.STP_TYPE,
            IF_INIT=reset_state,
            device=self.device,
        )

        if reset_state:
            state.u_ff_stp_last = torch.zeros_like(mod.u_stp)
            state.x_ff_stp_last = torch.zeros_like(mod.x_stp)
        else:
            mod.u_stp = state.u_ff_stp_last
            mod.x_stp = state.x_ff_stp_last

        return mod

    # ------------------------------------------------------------------
    # Hebbian update
    # ------------------------------------------------------------------

    def apply_hebbian(self, hebb_rates: torch.Tensor, rates: torch.Tensor, W_rec: torch.Tensor):
        for pre in range(self.N_POP):
            pre_rates = rates[:, self.slices[pre]]
            hebb_pre = hebb_rates[:, self.slices[pre]]

            for post in range(self.N_POP):
                idx = pre + post * self.N_POP
                if not self.IS_HEBB[idx]:
                    continue

                post_rates = rates[:, self.slices[post]]
                hebb_post = hebb_rates[:, self.slices[post]]

                W_hebb = self.hebb(pre_rates, post_rates, hebb_pre, hebb_post)
                W_hebb = W_hebb / torch.sqrt(self.Ka[0])

                W_rec[:, self.slices[pre], self.slices[post]] = (
                    self.W_rec_base[self.slices[pre], self.slices[post]].unsqueeze(0) + W_hebb
                )

        W_rec[:, self.slices[0]] = W_rec[:, self.slices[0]].clamp(min=0.0)
        if self.N_POP > 1:
            W_rec[:, self.slices[1]] = W_rec[:, self.slices[1]].clamp(max=0.0)

        if self.HEBB_TYPE == "bcm":
            hebb_rates = hebb_rates * self.EXP_HEBB + rates * (1.0 - self.EXP_HEBB)

        return W_rec, hebb_rates

    # ------------------------------------------------------------------
    # One-step dynamics
    # ------------------------------------------------------------------

    def _compute_stp_hidden(self, rates, stp_modules, W_stp):
        if not self.IF_STP:
            return None

        hidden_stp_total = torch.zeros((self.N_BATCH, self.N_NEURON), device=self.device)

        for k, (pre, post, _) in enumerate(self.stp_block_index):
            aux = stp_modules[k](rates[:, self.slices[pre]])
            hidden_block = aux @ W_stp[k]
            hidden_stp_total[:, self.slices[post]] += hidden_block

        return hidden_stp_total

    def step(self, state: NetworkState, ff_step: torch.Tensor, W_rec: torch.Tensor, W_stp, stp_modules, ff_stp_module):
        rates = state.rates
        rec_input = state.rec_input
        thresh = state.thresh
        ff_prev = state.ff_prev

        hidden = recurrent_matmul(rates, W_rec)

        hidden_stp_total = self._compute_stp_hidden(rates, stp_modules, W_stp)
        if hidden_stp_total is not None:
            hidden = hidden + hidden_stp_total

        if self.IF_FF_STP:
            hidden_ff_stp = torch.sign(ff_step) * (
                ff_stp_module(torch.abs(ff_step) / torch.sqrt(self.Ka[0])) * torch.sqrt(self.Ka[0])
            )
            ff_step = ff_step + hidden_ff_stp

        if self.IF_FF_DYN:
            ff_step = ff_prev * self.EXP_FF + ff_step * (1.0 - self.EXP_FF)
            ff_prev = ff_step

        if self.IF_BATCH_J:
            hidden[:, self.slices[0]].add_(
                self.Jab_batch * rates[:, self.slices[0]] @ self.W_batch_T
            )

        if self.SYN_DYN:
            rec_input[0] = rec_input[0] * self.EXP_DT_TAU_SYN + hidden * (1.0 - self.EXP_DT_TAU_SYN)
        else:
            rec_input[0] = hidden

        if self.IF_FF_ADAPT:
            ff_step = torch.sign(ff_step) * nn.ReLU()(ff_step - self.thresh_ff)
            self.thresh_ff = (
                self.thresh_ff * self.EXP_FF_ADAPT
                + nn.ReLU()(ff_step) * self.A_FF_ADAPT * (1.0 - self.EXP_FF_ADAPT)
            )

        net_input = ff_step + rec_input[0]

        if self.IF_NMDA:
            if W_rec.dim() == 2:
                hidden_nmda = recurrent_matmul(rates[:, self.slices[0]], W_rec[self.slices[0]])
            else:
                hidden_nmda = recurrent_matmul(rates[:, self.slices[0]], W_rec[:, self.slices[0]])

            if hidden_stp_total is not None:
                hidden_nmda[:, self.slices[0]] = hidden_nmda[:, self.slices[0]] + hidden_stp_total[:, self.slices[0]]

            rec_input[1] = (
                rec_input[1] * self.EXP_DT_TAU_NMDA
                + self.R_NMDA * hidden_nmda * (1.0 - self.EXP_DT_TAU_NMDA)
            )

            net_input = net_input + rec_input[1]

        non_linear = self.activation(net_input, func_name=self.TF_TYPE, thresh=thresh)

        if self.RATE_DYN:
            rates = rates * self.EXP_DT_TAU + non_linear * (1.0 - self.EXP_DT_TAU)
        else:
            rates = non_linear

        if self.IF_ADAPT:
            thresh[:, self.slices[0]] = (
                thresh[:, self.slices[0]] * self.EXP_ADAPT
                + rates[:, self.slices[0]].detach() * self.A_ADAPT * (1.0 - self.EXP_ADAPT)
            )

        state.rates = rates
        state.rec_input = rec_input
        state.thresh = thresh
        state.ff_prev = ff_prev

        return state

    # ------------------------------------------------------------------
    # Output accumulation
    # ------------------------------------------------------------------

    def _init_output_buffers(self):
        return {
            "rates": [],
            "rec": [],
            "stp_u": [],
            "stp_x": [],
        }

    def _accumulate_window(self, step, state, mv_rates, mv_rec, ret_rec):
        if step >= (self.N_STEADY + self.N_HEBB - self.N_WINDOW - 1):
            mv_rates = mv_rates + state.rates
            if ret_rec:
                mv_rec = mv_rec + state.rec_input
        return mv_rates, mv_rec

    def _maybe_emit_output(self, step, state, mv_rates, mv_rec, outputs, ret_rec, ret_stp, stp_modules):
        emit = (step >= (self.N_STEADY + self.N_HEBB)) and (step % self.N_WINDOW == 0)
        if not emit:
            return mv_rates, mv_rec

        if self.VERBOSE:
            print_activity(self, step, state.rates)

        outputs["rates"].append(mv_rates[:, self.slices[0]] / self.N_WINDOW)

        if ret_rec:
            outputs["rec"].append(mv_rec[..., self.slices[0]] / self.N_WINDOW)

        if self.IF_STP and ret_stp and stp_modules is not None:
            outputs["stp_x"].append(stp_modules[0].x_stp)
            outputs["stp_u"].append(stp_modules[0].u_stp)

        mv_rates = 0
        mv_rec = 0
        return mv_rates, mv_rec

    # ------------------------------------------------------------------
    # Persistent state saving
    # ------------------------------------------------------------------

    def _init_last_state_buffers(self, state: NetworkState):
        with torch.no_grad():
            self.rates_last = torch.zeros_like(state.rates.detach())
            self.rec_input_last = torch.zeros_like(state.rec_input.detach())
            self.thresh_last = torch.zeros_like(state.thresh.detach())
            self.ff_prev_last = torch.zeros_like(state.ff_prev.detach())
            self.end_mask = torch.ones((self.N_BATCH, 1), device=self.device)

            if self.IF_HEBB and state.hebb_rates is not None:
                self.hebb_rates_last = torch.zeros_like(state.hebb_rates.detach())

    def save_last_step(self, step, state: NetworkState, stp_modules=None, ff_stp_module=None):
        end_idx = torch.where(step == self.end_indices[-1])[0]

        self.end_mask[end_idx, 0] = float("nan")
        self.rates_last[end_idx] = state.rates[end_idx].detach()
        self.rec_input_last[:, end_idx] = state.rec_input[:, end_idx].detach()
        self.thresh_last[end_idx] = state.thresh[end_idx].detach()
        self.ff_prev_last[end_idx] = state.ff_prev[end_idx].detach()

        if self.IF_HEBB and state.hebb_rates is not None:
            self.hebb_rates_last[end_idx] = state.hebb_rates[end_idx].detach()

        if self.IF_STP and stp_modules is not None:
            if state.u_stp_last is None:
                state.u_stp_last = [torch.zeros_like(m.u_stp) for m in stp_modules]
                state.x_stp_last = [torch.zeros_like(m.x_stp) for m in stp_modules]

            for k, mod in enumerate(stp_modules):
                state.u_stp_last[k][end_idx] = mod.u_stp[end_idx].detach()
                state.x_stp_last[k][end_idx] = mod.x_stp[end_idx].detach()

        if self.IF_FF_STP and ff_stp_module is not None:
            if state.u_ff_stp_last is None:
                state.u_ff_stp_last = torch.zeros_like(ff_stp_module.u_stp)
                state.x_ff_stp_last = torch.zeros_like(ff_stp_module.x_stp)

            state.u_ff_stp_last[end_idx] = ff_stp_module.u_stp[end_idx].detach()
            state.x_ff_stp_last[end_idx] = ff_stp_module.x_stp[end_idx].detach()

    # ------------------------------------------------------------------
    # Final packaging
    # ------------------------------------------------------------------

    def _finalize_outputs(self, outputs, ret_rec=False, ret_stp=False):
        rates = torch.stack(outputs["rates"], dim=1)

        rec = None
        if ret_rec:
            rec = torch.stack(outputs["rec"], dim=2)

        stp_u = None
        stp_x = None
        if self.IF_STP and ret_stp:
            stp_u = torch.stack(outputs["stp_u"], dim=1)
            stp_x = torch.stack(outputs["stp_x"], dim=1)

        readout = None
        if self.LR_TRAIN:
            readout = rates @ self.low_rank.get_readout() / self.Na[0]

        return ForwardOutputs(
            rates=rates,
            rec_input=rec,
            stp_u=stp_u,
            stp_x=stp_x,
            readout=readout,
        )

    # ------------------------------------------------------------------
    # Main forward
    # ------------------------------------------------------------------

    def forward(self, ff_input=None, RET_STP=0, RET_REC=0, IF_INIT=1):
        ff_input = self._prepare_ff_input(ff_input)

        if IF_INIT:
            state = self.initialize_state(ff_input)
            if self.TRAINING == 0:
                self._init_last_state_buffers(state)
        else:
            state = self.restore_state()

        if self.IF_HEBB:
            self.hebb = Hebbian(self.ETA, self.DT, self.HEBB_TYPE, self.HEBB_FRAC)

        W_train = self.build_trainable_matrix()
        W_rec = self.build_effective_recurrent_weights()
        W_stp = self.build_effective_stp_weights(W_train)
        W_rec = self.expand_weights_for_hebbian(W_rec)

        stp_modules = self.make_stp_modules(state, reset_state=bool(IF_INIT))
        ff_stp_module = self.make_ff_stp_module(state, reset_state=bool(IF_INIT))

        if self.IF_OPTO and W_stp is not None and len(W_stp) > 0:
            rand_idx = torch.randperm(W_stp[0].size(0), device=W_stp[0].device)[: self.N_OPTO]
            W_stp[0][rand_idx] = 0

        outputs = self._init_output_buffers()
        mv_rates, mv_rec = 0, 0

        for step in range(self.N_STEPS):
            if self.IF_HEBB and (step >= self.N_HEBB):
                W_rec, state.hebb_rates = self.apply_hebbian(state.hebb_rates, state.rates, W_rec)

            if self.RATE_NOISE:
                rate_noise = torch.randn((self.N_BATCH, self.N_NEURON), device=self.device)
                state.rates = state.rates + rate_noise * self.VAR_RATE

            ff_step = live_ff_input(self, step, ff_input) if self.LIVE_FF_UPDATE else ff_input[:, step]

            state = self.step(
                state=state,
                ff_step=ff_step,
                W_rec=W_rec,
                W_stp=W_stp,
                stp_modules=stp_modules,
                ff_stp_module=ff_stp_module,
            )

            if (self.TRAINING == 0) and torch.any(step == self.end_indices[-1]):
                self.save_last_step(step, state, stp_modules=stp_modules, ff_stp_module=ff_stp_module)

            mv_rates, mv_rec = self._accumulate_window(step, state, mv_rates, mv_rec, RET_REC)

            mv_rates, mv_rec = self._maybe_emit_output(
                step, state, mv_rates, mv_rec, outputs, RET_REC, RET_STP, stp_modules
            )

        if self.IF_HEBB:
            self.W_hebb_T = W_rec

        final = self._finalize_outputs(outputs, ret_rec=bool(RET_REC), ret_stp=bool(RET_STP))

        self.rates_list = final.rates
        if final.rec_input is not None:
            self.rec_input = final.rec_input
        if final.stp_u is not None:
            self.u_list = final.stp_u
        if final.stp_x is not None:
            self.x_list = final.stp_x
        if final.readout is not None:
            self.readout = final.readout

        return final.rates

#+begin_src python
from dataclasses import dataclass
from typing import Optional

import torch
from torch import nn

from src.connectivity import Connectivity
from src.lr_utils import init_low_rank, clamp_tensor, normalize_tensor


def recurrent_matmul(rates: torch.Tensor, W: torch.Tensor) -> torch.Tensor:
    if W.dim() == 2:
        return rates @ W
    if W.dim() == 3:
        return torch.bmm(rates.unsqueeze(1), W).squeeze(1)
    raise ValueError(f"Unsupported shapes: rates={rates.shape}, W={W.shape}")


@dataclass
class WeightOutputs:
    W_train: Optional[torch.Tensor]
    W_rec: torch.Tensor
    W_stp: Optional[list]


class WeightBuilder(nn.Module):
    """
    Owns persistent weight-related parameters/buffers and builds effective weights.
    """

    def __init__(self, cfg):
        super().__init__()
        self.cfg = cfg
        self.device = cfg.device

        for k, v in vars(cfg).items():
            setattr(self, k, v)

        self._init_base_weights()
        self._init_trainable_weights()
        self._init_stp_buffers()
        self._init_low_rank_module()

    def _init_base_weights(self):
        W_rec = torch.zeros((self.N_NEURON, self.N_NEURON), device=self.device)

        for post in range(self.N_POP):
            for pre in range(self.N_POP):
                conn = Connectivity(
                    self.Na[post],
                    self.Na[pre],
                    self.Ka[pre],
                    device=self.device,
                )

                block = conn(
                    self.CON_TYPE,
                    self.PROBA_TYPE[post][pre],
                    kappa=self.KAPPA[post][pre],
                    phase=self.PHASE,
                    sigma=self.SIGMA[post][pre],
                    lr_mean=self.LR_MEAN,
                    lr_cov=self.LR_COV,
                    ksi=self.PHI0,
                )

                W_rec[self.slices[pre], self.slices[post]] = self.Jab[post][pre] * block.T

        self.register_buffer("W_rec_base", W_rec)

    def _init_trainable_weights(self):
        if self.TRAIN_EI:
            train_shape = (self.N_NEURON, self.N_NEURON)
        else:
            train_shape = (self.Na[0], self.Na[0])

        self.W_train_dense = None

        if not self.LR_TRAIN:
            self.W_train_dense = nn.Parameter(
                torch.randn(train_shape, device=self.device) * self.LR_INI
            )

        if self.TRAIN_EI:
            mask = torch.zeros(train_shape, device=self.device)
            for post in range(self.N_POP):
                for pre in range(self.N_POP):
                    mask[self.slices[pre], self.slices[post]] = self.IS_TRAIN[post][pre]
            self.register_buffer("train_mask", mask)
        else:
            self.train_mask = None

    def _init_low_rank_module(self):
        if self.LR_TRAIN:
            self.low_rank = init_low_rank(
                N_NEURON=self.Na[0],
                RANK=self.RANK,
                LR_MN=self.LR_MN,
                LR_READOUT=self.LR_READOUT,
                LR_INI=self.LR_INI,
                LR_UeqV=self.LR_UeqV,
                DEVICE=self.device,
                LR_TYPE=self.LR_TYPE,
                LR_N_SUPPORTS=self.LR_N_SUPPORTS,
                LR_SUPPORT_WEIGHTS=self.LR_SUPPORT_WEIGHTS,
                LR_BASIS_DIM=self.LR_BASIS_DIM,
                LR_TRAIN_BIASES=self.LR_TRAIN_BIASES,
                LR_READOUT_DIM=self.LR_READOUT_DIM,
                LR_INIT_GAUSSIAN_BASIS=self.LR_INIT_GAUSSIAN_BASIS,
            )
        else:
            self.low_rank = None

    def _init_stp_buffers(self):
        self.stp_block_index = []
        self.W_stp_blocks_base = []

        if not self.IF_STP:
            self.J_STP_param = None
            return

        J_stp = torch.tensor(self.J_STP, device=self.device, dtype=torch.float32)
        if getattr(self, "TRAIN_J_STP", False):
            self.J_STP_param = nn.Parameter(J_stp)
        else:
            self.register_buffer("J_STP_param", J_stp)

        for post in range(self.N_POP):
            for pre in range(self.N_POP):
                idx = pre + post * self.N_POP
                if not self.IS_STP[idx]:
                    continue

                pre_slice = self.slices[pre]
                post_slice = self.slices[post]

                block = self.W_rec_base[pre_slice, post_slice].clone() / torch.abs(self.Jab[post, pre])
                self.stp_block_index.append((pre, post, idx))
                self.W_stp_blocks_base.append(block)

    def build_trainable_matrix(self) -> Optional[torch.Tensor]:
        if self.LR_TRAIN:
            return self.low_rank(self.LR_NORM)
        return self.W_train_dense

    def build_recurrent(self, W_train: Optional[torch.Tensor]) -> torch.Tensor:
        W_rec = self.W_rec_base.clone()

        if W_train is None:
            return W_rec

        if self.TRAIN_EI:
            for pop_idx in range(self.N_POP):
                W_train = normalize_tensor(W_train, pop_idx, self.slices, self.train_scale)

            W_rec = W_rec + self.train_mask * W_train

            if self.CLAMP:
                for pop_idx in range(self.N_POP):
                    W_rec = clamp_tensor(W_rec.T, pop_idx, self.slices).T
        else:
            W_rec[self.slices[0], self.slices[0]] = (
                W_rec[self.slices[0], self.slices[0]]
                + self.GAIN * W_train / torch.sqrt(self.Ka[0])
            )

            if self.CLAMP:
                W_rec = clamp_tensor(W_rec.T, 0, self.slices).T

        return W_rec

    def build_stp(self, W_train: Optional[torch.Tensor]) -> Optional[list]:
        if not self.IF_STP:
            return None

        W_stp = []
        fix_scale = torch.sqrt(self.Ka[0])

        for k, (pre, post, idx) in enumerate(self.stp_block_index):
            base_block = self.W_stp_blocks_base[k]

            if pre == 0 and post == 0 and W_train is not None and not self.TRAIN_EI:
                block = (
                    self.GAIN
                    * self.J_STP_param
                    * (
                        base_block / fix_scale
                        * (1.0 + W_train[self.slices[0], self.slices[0]] / self.train_scale[0])
                    )
                )
                if self.CLAMP:
                    block = clamp_tensor(block, 0, self.slices)
            else:
                block = self.W_STP[idx] * self.J_STP_param * base_block / torch.sqrt(self.Ka[pre])

            W_stp.append(block)

        return W_stp

    def expand_for_hebbian(self, W_rec: torch.Tensor, batch_size: int) -> torch.Tensor:
        if not self.IF_HEBB:
            return W_rec
        return W_rec.unsqueeze(0).repeat(batch_size, 1, 1)

    def build_all(self, batch_size: int) -> WeightOutputs:
        W_train = self.build_trainable_matrix()
        W_rec = self.build_recurrent(W_train)
        W_stp = self.build_stp(W_train)
        W_rec = self.expand_for_hebbian(W_rec, batch_size)
        return WeightOutputs(W_train=W_train, W_rec=W_rec, W_stp=W_stp)

    def get_readout(self):
        if self.low_rank is None:
            return None
        return self.low_rank.get_readout()
#+end_src

from typing import Optional

import torch
from torch import nn

from src.hebbian import Hebbian
from src.plasticity import Plasticity


class PlasticityManager(nn.Module):
    """
    Builds per-forward plasticity modules and applies Hebbian updates.
    """

    def __init__(self, cfg, W_rec_base: torch.Tensor, stp_block_index):
        super().__init__()
        self.cfg = cfg
        self.W_rec_base = W_rec_base
        self.stp_block_index = stp_block_index

        for k, v in vars(cfg).items():
            setattr(self, k, v)

        self.hebb = None
        if self.IF_HEBB:
            self.hebb = Hebbian(self.ETA, self.DT, self.HEBB_TYPE, self.HEBB_FRAC)

    def make_stp_modules(self, state, batch_size: int, reset: bool):
        if not self.IF_STP:
            return None

        stp_modules = []
        u_last = [] if reset else state.u_stp_last
        x_last = [] if reset else state.x_stp_last

        for pre, post, idx in self.stp_block_index:
            mod = Plasticity(
                self.USE[idx],
                self.TAU_FAC[idx],
                self.TAU_REC[idx],
                self.DT,
                (batch_size, self.Na[pre]),
                STP_TYPE=self.STP_TYPE,
                IF_INIT=reset,
                device=self.device,
            )

            if reset:
                u_last.append(torch.zeros_like(mod.u_stp.detach()))
                x_last.append(torch.zeros_like(mod.x_stp.detach()))
            else:
                mod.u_stp = u_last[len(stp_modules)].detach()
                mod.x_stp = x_last[len(stp_modules)].detach()

            stp_modules.append(mod)

        state.u_stp_last = u_last
        state.x_stp_last = x_last
        return stp_modules

    def make_ff_stp_module(self, state, batch_size: int, reset: bool):
        if not self.IF_FF_STP:
            return None

        mod = Plasticity(
            self.FF_USE,
            self.TAU_FF_FAC,
            self.TAU_FF_REC,
            self.DT,
            (batch_size, self.N_NEURON),
            STP_TYPE=self.STP_TYPE,
            IF_INIT=reset,
            device=self.device,
        )

        if reset:
            state.u_ff_stp_last = torch.zeros_like(mod.u_stp)
            state.x_ff_stp_last = torch.zeros_like(mod.x_stp)
        else:
            mod.u_stp = state.u_ff_stp_last
            mod.x_stp = state.x_ff_stp_last

        return mod

    def apply_hebbian(self, hebb_rates: torch.Tensor, rates: torch.Tensor, W_rec: torch.Tensor):
        if not self.IF_HEBB:
            return W_rec, hebb_rates

        for pre in range(self.N_POP):
            pre_rates = rates[:, self.slices[pre]]
            hebb_pre = hebb_rates[:, self.slices[pre]]

            for post in range(self.N_POP):
                idx = pre + post * self.N_POP
                if not self.IS_HEBB[idx]:
                    continue

                post_rates = rates[:, self.slices[post]]
                hebb_post = hebb_rates[:, self.slices[post]]

                W_hebb = self.hebb(pre_rates, post_rates, hebb_pre, hebb_post)
                W_hebb = W_hebb / torch.sqrt(self.Ka[0])

                W_rec[:, self.slices[pre], self.slices[post]] = (
                    self.W_rec_base[self.slices[pre], self.slices[post]].unsqueeze(0) + W_hebb
                )

        W_rec[:, self.slices[0]] = W_rec[:, self.slices[0]].clamp(min=0.0)
        if self.N_POP > 1:
            W_rec[:, self.slices[1]] = W_rec[:, self.slices[1]].clamp(max=0.0)

        if self.HEBB_TYPE == "bcm":
            hebb_rates = hebb_rates * self.EXP_HEBB + rates * (1.0 - self.EXP_HEBB)

        return W_rec, hebb_rates

#+begin_src python
import torch
from torch import nn

from src.activation import Activation
from src.network_weights import recurrent_matmul


class DynamicsCore(nn.Module):
    """
    One-step dynamics update.
    """

    def __init__(self, cfg):
        super().__init__()
        self.cfg = cfg
        self.activation = Activation()

        for k, v in vars(cfg).items():
            setattr(self, k, v)

    def _compute_stp_hidden(self, rates, batch_size, stp_modules, W_stp):
        if not self.IF_STP or stp_modules is None or W_stp is None:
            return None

        hidden_stp_total = torch.zeros((batch_size, self.N_NEURON), device=self.device)

        for k, (pre, post, _) in enumerate(self.stp_block_index):
            aux = stp_modules[k](rates[:, self.slices[pre]])
            hidden_block = aux @ W_stp[k]
            hidden_stp_total[:, self.slices[post]] += hidden_block

        return hidden_stp_total

    def step(self, state, ff_step, W_rec, W_stp, stp_modules, ff_stp_module):
        rates = state.rates
        rec_input = state.rec_input
        thresh = state.thresh
        ff_prev = state.ff_prev

        batch_size = rates.shape[0]

        hidden = recurrent_matmul(rates, W_rec)

        hidden_stp_total = self._compute_stp_hidden(rates, batch_size, stp_modules, W_stp)
        if hidden_stp_total is not None:
            hidden = hidden + hidden_stp_total

        if self.IF_FF_STP and ff_stp_module is not None:
            hidden_ff_stp = torch.sign(ff_step) * (
                ff_stp_module(torch.abs(ff_step) / torch.sqrt(self.Ka[0])) * torch.sqrt(self.Ka[0])
            )
            ff_step = ff_step + hidden_ff_stp

        if self.IF_FF_DYN:
            ff_step = ff_prev * self.EXP_FF + ff_step * (1.0 - self.EXP_FF)
            ff_prev = ff_step

        if self.IF_BATCH_J:
            hidden[:, self.slices[0]].add_(
                self.Jab_batch * rates[:, self.slices[0]] @ self.W_batch_T
            )

        if self.SYN_DYN:
            rec_input[0] = rec_input[0] * self.EXP_DT_TAU_SYN + hidden * (1.0 - self.EXP_DT_TAU_SYN)
        else:
            rec_input[0] = hidden

        if self.IF_FF_ADAPT:
            ff_step = torch.sign(ff_step) * nn.ReLU()(ff_step - self.thresh_ff)
            self.thresh_ff = (
                self.thresh_ff * self.EXP_FF_ADAPT
                + nn.ReLU()(ff_step) * self.A_FF_ADAPT * (1.0 - self.EXP_FF_ADAPT)
            )

        net_input = ff_step + rec_input[0]

        if self.IF_NMDA:
            if W_rec.dim() == 2:
                hidden_nmda = recurrent_matmul(rates[:, self.slices[0]], W_rec[self.slices[0]])
            else:
                hidden_nmda = recurrent_matmul(rates[:, self.slices[0]], W_rec[:, self.slices[0]])

            if hidden_stp_total is not None:
                hidden_nmda[:, self.slices[0]] += hidden_stp_total[:, self.slices[0]]

            rec_input[1] = (
                rec_input[1] * self.EXP_DT_TAU_NMDA
                + self.R_NMDA * hidden_nmda * (1.0 - self.EXP_DT_TAU_NMDA)
            )
            net_input = net_input + rec_input[1]

        non_linear = self.activation(net_input, func_name=self.TF_TYPE, thresh=thresh)

        if self.RATE_DYN:
            rates = rates * self.EXP_DT_TAU + non_linear * (1.0 - self.EXP_DT_TAU)
        else:
            rates = non_linear

        if self.IF_ADAPT:
            thresh[:, self.slices[0]] = (
                thresh[:, self.slices[0]] * self.EXP_ADAPT
                + rates[:, self.slices[0]].detach() * self.A_ADAPT * (1.0 - self.EXP_ADAPT)
            )

        state.rates = rates
        state.rec_input = rec_input

class OutputCollector:

        self.thresh_last = None

        self.hebb_rates_last = None
        self.end_mask = None

    def prepare_ff_input(self, ff_input):
        if ff_input is None:
            ff_input = init_ff_input(self)
        return ff_input.to(self.device)

    def initialize(self, ff_input):
        self.N_BATCH = ff_input.shape[0]

        thresh = self.thresh[: self.N_BATCH].clone()
        rec_input = torch.randn(
            (self.IF_NMDA + 1, self.N_BATCH, self.N_NEURON),
            device=self.device,
        )

        ff0 = ff_input if self.LIVE_FF_UPDATE else ff_input[:, 0]

        if self.IF_FF_ADAPT:
            self.thresh_ff = torch.zeros_like(ff_input[:, 0])

        rates = self.activation(ff0 + rec_input[0], func_name=self.TF_TYPE, thresh=thresh)
        hebb_rates = rates.clone() if self.IF_HEBB else None

        return NetworkState(
            rates=rates,
            rec_input=rec_input,
            thresh=thresh,
            ff_prev=torch.zeros_like(ff0),
            hebb_rates=hebb_rates,
        )

    def restore(self):
        return NetworkState(
            rates=self.rates_last,
            rec_input=self.rec_input_last,
            thresh=self.thresh_last,
            ff_prev=self.ff_prev_last,
            hebb_rates=self.hebb_rates_last,
        )

    def init_last_state_buffers(self, state, batch_size):
        self.rates_last = torch.zeros_like(state.rates.detach())
        self.rec_input_last = torch.zeros_like(state.rec_input.detach())
        self.thresh_last = torch.zeros_like(state.thresh.detach())
        self.ff_prev_last = torch.zeros_like(state.ff_prev.detach())
        self.end_mask = torch.ones((batch_size, 1), device=self.device)

        if self.IF_HEBB and state.hebb_rates is not None:
            self.hebb_rates_last = torch.zeros_like(state.hebb_rates.detach())

    def maybe_save(self, step, state, end_indices, stp_modules=None, ff_stp_module=None):
        if not torch.any(step == end_indices[-1]):
            return

        end_idx = torch.where(step == end_indices[-1])[0]

        self.end_mask[end_idx, 0] = float("nan")
        self.rates_last[end_idx] = state.rates[end_idx].detach()
        self.rec_input_last[:, end_idx] = state.rec_input[:, end_idx].detach()
        self.thresh_last[end_idx] = state.thresh[end_idx].detach()
        self.ff_prev_last[end_idx] = state.ff_prev[end_idx].detach()

        if self.IF_HEBB and state.hebb_rates is not None:
            self.hebb_rates_last[end_idx] = state.hebb_rates[end_idx].detach()

        if stp_modules is not None:
            if state.u_stp_last is None:

import warnings

import torch
from torch import nn

from src.configuration import Configuration

from src.utils import set_seed, clear_cache

from src.network_dynamics import DynamicsCore
from src.network_outputs import OutputCollector
from src.network_plasticity import PlasticityManager
from src.network_state_mgr import StateManager
from src.network_weights import WeightBuilder

warnings.filterwarnings("ignore")


class Network(nn.Module):
    """
    Thin orchestrator around state, weights, plasticity, dynamics, and outputs.
    """

    def __init__(self, conf_name, repo_root, **kwargs):
        super().__init__()

        self.config = Configuration(conf_name, repo_root)(**kwargs)
        self._load_config(self.config)

        self.weight_builder = WeightBuilder(self.config)
        self.state_manager = StateManager(self.config, activation=self._activation_fn())
        self.plasticity_manager = PlasticityManager(
            self.config,
            W_rec_base=self.weight_builder.W_rec_base,
            stp_block_index=self.weight_builder.stp_block_index,
        )
        self.dynamics = DynamicsCore(self.config)

        set_seed(-1)
        clear_cache()

    def _load_config(self, config):
        for key, value in vars(config).items():
            if hasattr(self, key):
                raise ValueError(f"Config key collision: {key}")
            setattr(self, key, value)

    def _activation_fn(self):
        from src.activation import Activation
        return Activation()

    def init_ff_input(self):
        return self.state_manager.prepare_ff_input(None)

    def forward(self, ff_input=None, RET_STP=0, RET_REC=0, IF_INIT=1):
        ff_input = self.state_manager.prepare_ff_input(ff_input)

        if IF_INIT:
            state = self.state_manager.initialize(ff_input)
            if self.TRAINING == 0:
                self.state_manager.init_last_state_buffers(state, ff_input.shape[0])
        else:
            state = self.state_manager.restore()

        batch_size = state.rates.shape[0]

        weights = self.weight_builder.build_all(batch_size=batch_size)

        stp_modules = self.plasticity_manager.make_stp_modules(
            state, batch_size=batch_size, reset=bool(IF_INIT)
        )
        ff_stp_module = self.plasticity_manager.make_ff_stp_module(
            state, batch_size=batch_size, reset=bool(IF_INIT)
        )

        if self.IF_OPTO and weights.W_stp is not None and len(weights.W_stp) > 0:
            rand_idx = torch.randperm(weights.W_stp[0].size(0), device=weights.W_stp[0].device)[: self.N_OPTO]
            weights.W_stp[0][rand_idx] = 0

        collector = OutputCollector(self.config, return_rec=bool(RET_REC), return_stp=bool(RET_STP))

        for step in range(self.N_STEPS):
            if self.IF_HEBB and step >= self.N_HEBB:
                weights.W_rec, state.hebb_rates = self.plasticity_manager.apply_hebbian(
                    state.hebb_rates, state.rates, weights.W_rec
                )

            if self.RATE_NOISE:
                rate_noise = torch.randn((batch_size, self.N_NEURON), device=self.device)
                state.rates = state.rates + rate_noise * self.VAR_RATE

            ff_step = live_ff_input(self, step, ff_input) if self.LIVE_FF_UPDATE else ff_input[:, step]

            state = self.dynamics.step(
                state=state,
                ff_step=ff_step,
                W_rec=weights.W_rec,
                W_stp=weights.W_stp,
                stp_modules=stp_modules,
                ff_stp_module=ff_stp_module,
            )

            if self.TRAINING == 0:
                self.state_manager.maybe_save(
                    step,
                    state,
                    self.end_indices,
                    stp_modules=stp_modules,
                    ff_stp_module=ff_stp_module,
                )

            collector.update(step, state, stp_modules=stp_modules)

        readout = None
        if self.LR_TRAIN:
            readout = collector.outputs["rates"]
            readout = torch.stack(readout, dim=1) @ self.weight_builder.get_readout() / self.Na[0]

        final = collector.finalize(readout=readout)

        self.rates_list = final.rates
        if final.rec_input is not None:
            self.rec_input = final.rec_input
        if final.stp_u is not None:
            self.u_list = final.stp_u
        if final.stp_x is not None:
            self.x_list = final.stp_x
        if final.readout is not None:
            self.readout = final.readout

        if self.IF_HEBB:
            self.W_hebb_T = weights.W_rec

        return final.rates

from dataclasses import dataclass
from typing import Optional

import torch
from torch import nn

from src.connectivity import Connectivity
from src.lr_utils import init_low_rank, clamp_tensor, normalize_tensor


def recurrent_matmul(rates: torch.Tensor, W: torch.Tensor) -> torch.Tensor:
    if W.dim() == 2:
        return rates @ W
    if W.dim() == 3:
        return torch.bmm(rates.unsqueeze(1), W).squeeze(1)
    raise ValueError(f"Unsupported shapes: rates={rates.shape}, W={W.shape}")


@dataclass
class WeightOutputs:
    W_train: Optional[torch.Tensor]
    W_rec: torch.Tensor
    W_stp: Optional[list]


class WeightBuilder(nn.Module):
    """
    Owns persistent weight-related parameters/buffers and builds effective weights.
    Convention: W_rec[pre, post].
    """

    def __init__(self, cfg):
        super().__init__()
        self.cfg = cfg
        self.device = cfg.device

        for k, v in vars(cfg).items():
            setattr(self, k, v)

        self._init_base_weights()
        self._init_trainable_weights()
        self._init_stp_buffers()
        self._init_low_rank_module()

    def _init_base_weights(self):
        W_rec = torch.zeros((self.N_NEURON, self.N_NEURON), device=self.device)

        for post in range(self.N_POP):
            for pre in range(self.N_POP):
                conn = Connectivity(
                    self.Na[post],
                    self.Na[pre],
                    self.Ka[pre],
                    device=self.device,
                )

                block = conn(
                    self.CON_TYPE,
                    self.PROBA_TYPE[post][pre],
                    kappa=self.KAPPA[post][pre],
                    phase=self.PHASE,
                    sigma=self.SIGMA[post][pre],
                    lr_mean=self.LR_MEAN,
                    lr_cov=self.LR_COV,
                    ksi=self.PHI0,
                )

                # block assumed [post, pre] -> store [pre, post]
                W_rec[self.slices[pre], self.slices[post]] = self.Jab[post][pre] * block.T

        self.register_buffer("W_rec_base", W_rec)

    def _init_trainable_weights(self):
        if self.TRAIN_EI:
            train_shape = (self.N_NEURON, self.N_NEURON)
        else:
            train_shape = (self.Na[0], self.Na[0])

        self.W_train_dense = None

        if not self.LR_TRAIN:
            self.W_train_dense = nn.Parameter(
                torch.randn(train_shape, device=self.device) * self.LR_INI
            )

        if self.TRAIN_EI:
            mask = torch.zeros(train_shape, device=self.device)
            for post in range(self.N_POP):
                for pre in range(self.N_POP):
                    mask[self.slices[pre], self.slices[post]] = self.IS_TRAIN[post][pre]
            self.register_buffer("train_mask", mask)
        else:
            self.train_mask = None

    def _init_low_rank_module(self):
        if self.LR_TRAIN:
            self.low_rank = init_low_rank(
                N_NEURON=self.Na[0],
                RANK=self.RANK,
                LR_MN=self.LR_MN,
                LR_READOUT=self.LR_READOUT,
                LR_INI=self.LR_INI,
                LR_UeqV=self.LR_UeqV,
                DEVICE=self.device,
                LR_TYPE=self.LR_TYPE,
                LR_N_SUPPORTS=self.LR_N_SUPPORTS,
                LR_SUPPORT_WEIGHTS=self.LR_SUPPORT_WEIGHTS,
                LR_BASIS_DIM=self.LR_BASIS_DIM,
                LR_TRAIN_BIASES=self.LR_TRAIN_BIASES,
                LR_READOUT_DIM=self.LR_READOUT_DIM,
                LR_INIT_GAUSSIAN_BASIS=self.LR_INIT_GAUSSIAN_BASIS,
            )
        else:
            self.low_rank = None

    def _init_stp_buffers(self):
        self.stp_block_index = []
        self.W_stp_blocks_base = []

        if not self.IF_STP:
            self.J_STP_param = None
            return

        J_stp = torch.as_tensor(self.J_STP, device=self.device, dtype=torch.float32)
        if getattr(self, "TRAIN_J_STP", False):
            self.J_STP_param = nn.Parameter(J_stp)
        else:
            self.register_buffer("J_STP_param", J_stp)

        for post in range(self.N_POP):
            for pre in range(self.N_POP):
                idx = pre + post * self.N_POP
                if not self.IS_STP[idx]:
                    continue

                pre_slice = self.slices[pre]
                post_slice = self.slices[post]

                block = self.W_rec_base[pre_slice, post_slice].clone() / torch.abs(self.Jab[post, pre])
                self.stp_block_index.append((pre, post, idx))
                self.W_stp_blocks_base.append(block)

    def build_trainable_matrix(self) -> Optional[torch.Tensor]:
        if self.LR_TRAIN:
            return self.low_rank(self.LR_NORM)
        return self.W_train_dense

    def build_recurrent(self, W_train: Optional[torch.Tensor]) -> torch.Tensor:
        W_rec = self.W_rec_base.clone()

        if W_train is None:
            return W_rec

        if self.TRAIN_EI:
            W_eff = W_train
            for pop_idx in range(self.N_POP):
                W_eff = normalize_tensor(W_eff, pop_idx, self.slices, self.train_scale)

            W_rec = W_rec + self.train_mask * W_eff

            if self.CLAMP:
                for pop_idx in range(self.N_POP):
                    W_rec = clamp_tensor(W_rec.T, pop_idx, self.slices).T
        else:
            ee = self.slices[0]
            W_rec[ee, ee] = W_rec[ee, ee] + self.GAIN * W_train / torch.sqrt(self.Ka[0])

            if self.CLAMP:
                W_rec = clamp_tensor(W_rec.T, 0, self.slices).T

        return W_rec

    def build_stp(self, W_train: Optional[torch.Tensor]) -> Optional[list]:
        if not self.IF_STP:
            return None

        W_stp = []
        fix_scale = torch.sqrt(self.Ka[0])

        for k, (pre, post, idx) in enumerate(self.stp_block_index):
            base_block = self.W_stp_blocks_base[k]

            if pre == 0 and post == 0 and W_train is not None and not self.TRAIN_EI:
                block = (
                    self.GAIN
                    * self.J_STP_param
                    * (
                        base_block / fix_scale
                        * (1.0 + W_train / self.train_scale[0])
                    )
                )
                if self.CLAMP:
                    block = clamp_tensor(block, 0, self.slices)
            else:
                block = self.W_STP[idx] * self.J_STP_param * base_block / torch.sqrt(self.Ka[pre])

            W_stp.append(block)

        return W_stp

    def expand_for_hebbian(self, W_rec: torch.Tensor, batch_size: int) -> torch.Tensor:
        if not self.IF_HEBB:
            return W_rec
        return W_rec.unsqueeze(0).repeat(batch_size, 1, 1)

    def build_all(self, batch_size: int) -> WeightOutputs:
        W_train = self.build_trainable_matrix()
        W_rec = self.build_recurrent(W_train)
        W_stp = self.build_stp(W_train)
        W_rec = self.expand_for_hebbian(W_rec, batch_size)
        return WeightOutputs(W_train=W_train, W_rec=W_rec, W_stp=W_stp)

    def get_readout(self):
        return None if self.low_rank is None else self.low_rank.get_readout()

import torch
from torch import nn

from src.hebbian import Hebbian
from src.plasticity import Plasticity


class PlasticityManager(nn.Module):
    """
    Builds per-forward plasticity modules and applies Hebbian updates.
    """

    def __init__(self, cfg, W_rec_base: torch.Tensor, stp_block_index):
        super().__init__()
        self.cfg = cfg
        self.W_rec_base = W_rec_base
        self.stp_block_index = stp_block_index

        for k, v in vars(cfg).items():
            setattr(self, k, v)

        self.hebb = Hebbian(self.ETA, self.DT, self.HEBB_TYPE, self.HEBB_FRAC) if self.IF_HEBB else None

    def make_stp_modules(self, state, batch_size: int, reset: bool):
        if not self.IF_STP:
            return None

        stp_modules = []
        u_last = [] if reset else state.u_stp_last
        x_last = [] if reset else state.x_stp_last

        for pre, post, idx in self.stp_block_index:
            mod = Plasticity(
                self.USE[idx],
                self.TAU_FAC[idx],
                self.TAU_REC[idx],
                self.DT,
                (batch_size, self.Na[pre]),
                STP_TYPE=self.STP_TYPE,
                IF_INIT=reset,
                device=self.device,
            )

            if reset:
                u_last.append(torch.zeros_like(mod.u_stp.detach()))
                x_last.append(torch.zeros_like(mod.x_stp.detach()))
            else:
                mod.u_stp = u_last[len(stp_modules)].detach()
                mod.x_stp = x_last[len(stp_modules)].detach()

            stp_modules.append(mod)

        state.u_stp_last = u_last
        state.x_stp_last = x_last
        return stp_modules

    def make_ff_stp_module(self, state, batch_size: int, reset: bool):
        if not self.IF_FF_STP:
            return None

        mod = Plasticity(
            self.FF_USE,
            self.TAU_FF_FAC,
            self.TAU_FF_REC,
            self.DT,
            (batch_size, self.N_NEURON),
            STP_TYPE=self.STP_TYPE,
            IF_INIT=reset,
            device=self.device,
        )

        if reset:
            state.u_ff_stp_last = torch.zeros_like(mod.u_stp)
            state.x_ff_stp_last = torch.zeros_like(mod.x_stp)
        else:
            mod.u_stp = state.u_ff_stp_last
            mod.x_stp = state.x_ff_stp_last

        return mod

    def apply_hebbian(self, hebb_rates: torch.Tensor, rates: torch.Tensor, W_rec: torch.Tensor):
        if not self.IF_HEBB:
            return W_rec, hebb_rates

        for pre in range(self.N_POP):
            pre_rates = rates[:, self.slices[pre]]
            hebb_pre = hebb_rates[:, self.slices[pre]]

            for post in range(self.N_POP):
                idx = pre + post * self.N_POP
                if not self.IS_HEBB[idx]:
                    continue

                post_rates = rates[:, self.slices[post]]
                hebb_post = hebb_rates[:, self.slices[post]]

                W_hebb = self.hebb(pre_rates, post_rates, hebb_pre, hebb_post)
                W_hebb = W_hebb / torch.sqrt(self.Ka[0])

                W_rec[:, self.slices[pre], self.slices[post]] = (
                    self.W_rec_base[self.slices[pre], self.slices[post]].unsqueeze(0) + W_hebb
                )

        W_rec[:, self.slices[0]] = W_rec[:, self.slices[0]].clamp(min=0.0)
        if self.N_POP > 1:
            W_rec[:, self.slices[1]] = W_rec[:, self.slices[1]].clamp(max=0.0)

        if self.HEBB_TYPE == "bcm":
            hebb_rates = hebb_rates * self.EXP_HEBB + rates * (1.0 - self.EXP_HEBB)

        return W_rec, hebb_rates

import torch
from torch import nn

from src.activation import Activation
from src.network_weights import recurrent_matmul


class DynamicsCore(nn.Module):
    """
    One-step dynamics update.
    """

    def __init__(self, cfg, stp_block_index):
        super().__init__()
        self.cfg = cfg
        self.stp_block_index = stp_block_index
        self.activation = Activation()

        for k, v in vars(cfg).items():
            setattr(self, k, v)

        self.thresh_ff = None

    def reset_buffers(self, batch_size: int, ff_shape: torch.Size | None = None):
        if self.IF_FF_ADAPT and ff_shape is not None:
            self.thresh_ff = torch.zeros(ff_shape, device=self.device)

    def _compute_stp_hidden(self, rates, batch_size, stp_modules, W_stp):
        if not self.IF_STP or stp_modules is None or W_stp is None:
            return None

        hidden_stp_total = torch.zeros((batch_size, self.N_NEURON), device=self.device)

        for k, (pre, post, _) in enumerate(self.stp_block_index):
            aux = stp_modules[k](rates[:, self.slices[pre]])
            hidden_block = aux @ W_stp[k]
            hidden_stp_total[:, self.slices[post]] += hidden_block

        return hidden_stp_total

    def step(self, state, ff_step, W_rec, W_stp, stp_modules, ff_stp_module):
        rates = state.rates
        rec_input = state.rec_input
        thresh = state.thresh
        ff_prev = state.ff_prev

        batch_size = rates.shape[0]
        hidden = recurrent_matmul(rates, W_rec)

        hidden_stp_total = self._compute_stp_hidden(rates, batch_size, stp_modules, W_stp)
        if hidden_stp_total is not None:
            hidden = hidden + hidden_stp_total

        if self.IF_FF_STP and ff_stp_module is not None:
            hidden_ff_stp = torch.sign(ff_step) * (
                ff_stp_module(torch.abs(ff_step) / torch.sqrt(self.Ka[0])) * torch.sqrt(self.Ka[0])
            )
            ff_step = ff_step + hidden_ff_stp

        if self.IF_FF_DYN:
            ff_step = ff_prev * self.EXP_FF + ff_step * (1.0 - self.EXP_FF)
            ff_prev = ff_step

        if self.IF_BATCH_J:
            hidden[:, self.slices[0]].add_(
                self.Jab_batch * rates[:, self.slices[0]] @ self.W_batch_T
            )

        if self.SYN_DYN:
            rec_input[0] = rec_input[0] * self.EXP_DT_TAU_SYN + hidden * (1.0 - self.EXP_DT_TAU_SYN)
        else:
            rec_input[0] = hidden

        if self.IF_FF_ADAPT:
            if self.thresh_ff is None:
                self.thresh_ff = torch.zeros_like(ff_step)

            ff_step = torch.sign(ff_step) * nn.ReLU()(ff_step - self.thresh_ff)
            self.thresh_ff = (
                self.thresh_ff * self.EXP_FF_ADAPT
                + nn.ReLU()(ff_step) * self.A_FF_ADAPT * (1.0 - self.EXP_FF_ADAPT)
            )

        net_input = ff_step + rec_input[0]

        if self.IF_NMDA:
            if W_rec.dim() == 2:
                hidden_nmda = recurrent_matmul(rates[:, self.slices[0]], W_rec[self.slices[0]])
            else:
                hidden_nmda = recurrent_matmul(rates[:, self.slices[0]], W_rec[:, self.slices[0]])

            if hidden_stp_total is not None:
                hidden_nmda[:, self.slices[0]] += hidden_stp_total[:, self.slices[0]]

            rec_input[1] = (
                rec_input[1] * self.EXP_DT_TAU_NMDA
                + self.R_NMDA * hidden_nmda * (1.0 - self.EXP_DT_TAU_NMDA)
            )
            net_input = net_input + rec_input[1]

        non_linear = self.activation(net_input, func_name=self.TF_TYPE, thresh=thresh)

        if self.RATE_DYN:
            rates = rates * self.EXP_DT_TAU + non_linear * (1.0 - self.EXP_DT_TAU)
        else:
            rates = non_linear

        if self.IF_ADAPT:
            thresh[:, self.slices[0]] = (
                thresh[:, self.slices[0]] * self.EXP_ADAPT
                + rates[:, self.slices[0]].detach() * self.A_ADAPT * (1.0 - self.EXP_ADAPT)
            )

        state.rates = rates
        state.rec_input = rec_input
        state.thresh = thresh
        state.ff_prev = ff_prev
        return state

class OutputCollector:

            self.mv_rates = self.mv_rates + state.rates

            return

        self.mv_rec = 0

class StateManager:
    """
    Handles initialization, restoration, and persistence of transient network state.
    """

    def __init__(self, cfg, activation):
        self.cfg = cfg
        self.activation = activation

        for k, v in vars(cfg).items():
            setattr(self, k, v)

        self.rates_last = None
        self.rec_input_last = None
        self.thresh_last = None
        self.ff_prev_last = None
        self.hebb_rates_last = None
        self.end_mask = None

    def initialize(self, ff_input):
        batch_size = ff_input.shape[0]
        thresh = self.thresh[:batch_size].clone()

        rec_input = torch.randn(
            (self.IF_NMDA + 1, batch_size, self.N_NEURON),
            device=self.device,
        )

        ff0 = ff_input if self.LIVE_FF_UPDATE else ff_input[:, 0]
        rates = self.activation(ff0 + rec_input[0], func_name=self.TF_TYPE, thresh=thresh)
        hebb_rates = rates.clone() if self.IF_HEBB else None

        return NetworkState(
            rates=rates,
            rec_input=rec_input,
            thresh=thresh,
            ff_prev=torch.zeros_like(ff0),
            hebb_rates=hebb_rates,
        )

    def restore(self):
        return NetworkState(
            rates=self.rates_last,
            rec_input=self.rec_input_last,
            thresh=self.thresh_last,
            ff_prev=self.ff_prev_last,
            hebb_rates=self.hebb_rates_last,
        )

    def init_last_state_buffers(self, state, batch_size):
        self.rates_last = torch.zeros_like(state.rates.detach())
        self.rec_input_last = torch.zeros_like(state.rec_input.detach())
        self.thresh_last = torch.zeros_like(state.thresh.detach())
        self.ff_prev_last = torch.zeros_like(state.ff_prev.detach())
        self.end_mask = torch.ones((batch_size, 1), device=self.device)

        if self.IF_HEBB and state.hebb_rates is not None:
            self.hebb_rates_last = torch.zeros_like(state.hebb_rates.detach())

    def maybe_save(self, step, state, end_indices, stp_modules=None, ff_stp_module=None):
        if not torch.any(step == end_indices[-1]):
            return

        end_idx = torch.where(step == end_indices[-1])[0]

        self.end_mask[end_idx, 0] = float("nan")
        self.rates_last[end_idx] = state.rates[end_idx].detach()
        self.rec_input_last[:, end_idx] = state.rec_input[:, end_idx].detach()
        self.thresh_last[end_idx] = state.thresh[end_idx].detach()
        self.ff_prev_last[end_idx] = state.ff_prev[end_idx].detach()

        if self.IF_HEBB and state.hebb_rates is not None:
            self.hebb_rates_last[end_idx] = state.hebb_rates[end_idx].detach()

        if stp_modules is not None:
            if state.u_stp_last is None:
                state.u_stp_last = [torch.zeros_like(m.u_stp) for m in stp_modules]
                state.x_stp_last = [torch.zeros_like(m.x_stp) for m in stp_modules]
            for k, mod in enumerate(stp_modules):
                state.u_stp_last[k][end_idx] = mod.u_stp[end_idx].detach()
                state.x_stp_last[k][end_idx] = mod.x_stp[end_idx].detach()

        if ff_stp_module is not None:
            if state.u_ff_stp_last is None:
                state.u_ff_stp_last = torch.zeros_like(ff_stp_module.u_stp)
                state.x_ff_stp_last = torch.zeros_like(ff_stp_module.x_stp)
            state.u_ff_stp_last[end_idx] = ff_stp_module.u_stp[end_idx].detach()
            state.x_ff_stp_last[end_idx] = ff_stp_module.x_stp[end_idx].detach()

from __future__ import annotations

from dataclasses import dataclass
from typing import Optional

import torch
from torch import nn

from src.connectivity import Connectivity
from src.lr_utils import clamp_tensor, init_low_rank, normalize_tensor


def recurrent_matmul(rates: torch.Tensor, W: torch.Tensor) -> torch.Tensor:
    """
    rates: (B, N)
    W:     (N, M) or (B, N, M)
    out:   (B, M)

    Convention:
        W[pre, post], so rates @ W gives postsynaptic input.
    """
    if rates.dim() != 2:
        raise ValueError(f"rates must be 2D, got shape {tuple(rates.shape)}")
    if W.dim() == 2:
        if rates.shape[1] != W.shape[0]:
            raise ValueError(f"Incompatible shapes: rates {tuple(rates.shape)}, W {tuple(W.shape)}")
        return rates @ W
    if W.dim() == 3:
        if rates.shape[0] != W.shape[0] or rates.shape[1] != W.shape[1]:
            raise ValueError(f"Incompatible shapes: rates {tuple(rates.shape)}, W {tuple(W.shape)}")
        return torch.bmm(rates.unsqueeze(1), W).squeeze(1)
    raise ValueError(f"Unsupported W shape {tuple(W.shape)}")


@dataclass
class WeightOutputs:
    W_train: Optional[torch.Tensor]
    W_rec: torch.Tensor
    W_stp: Optional[list[torch.Tensor]]


class WeightBuilder(nn.Module):
    """
    Owns persistent weight-related parameters/buffers and builds effective weights.
    Convention: W_rec[pre, post].
    """

    def __init__(self, cfg) -> None:
        super().__init__()
        self.cfg = cfg
        self.device = cfg.device

        for k, v in vars(cfg).items():
            setattr(self, k, v)

        self._init_base_weights()
        self._init_trainable_weights()
        self._init_stp_buffers()
        self._init_low_rank_module()

    def _init_base_weights(self) -> None:
        W_rec = torch.zeros((self.N_NEURON, self.N_NEURON), device=self.device)

        for post in range(self.N_POP):
            for pre in range(self.N_POP):
                conn = Connectivity(
                    self.Na[post],
                    self.Na[pre],
                    self.Ka[pre],
                    device=self.device,
                )

                block = conn(
                    self.CON_TYPE,
                    self.PROBA_TYPE[post][pre],
                    kappa=self.KAPPA[post][pre],
                    phase=self.PHASE,
                    sigma=self.SIGMA[post][pre],
                    lr_mean=self.LR_MEAN,
                    lr_cov=self.LR_COV,
                    ksi=self.PHI0,
                )

                expected = (self.Na[post], self.Na[pre])
                if tuple(block.shape) != expected:
                    raise ValueError(f"Connectivity block shape {tuple(block.shape)} != expected {expected}")

                W_rec[self.slices[pre], self.slices[post]] = self.Jab[post][pre] * block.T

        self.register_buffer("W_rec_base", W_rec)

    def _init_trainable_weights(self) -> None:
        train_shape = (self.N_NEURON, self.N_NEURON) if self.TRAIN_EI else (self.Na[0], self.Na[0])
        self.W_train_dense: Optional[nn.Parameter] = None

        if not self.LR_TRAIN:
            self.W_train_dense = nn.Parameter(
                torch.randn(train_shape, device=self.device) * self.LR_INI
            )

        if self.TRAIN_EI:
            mask = torch.zeros(train_shape, device=self.device)
            for post in range(self.N_POP):
                for pre in range(self.N_POP):
                    mask[self.slices[pre], self.slices[post]] = self.IS_TRAIN[post][pre]
            self.register_buffer("train_mask", mask)
        else:
            self.train_mask = None

    def _init_low_rank_module(self) -> None:
        if self.LR_TRAIN:
            self.low_rank = init_low_rank(
                N_NEURON=self.Na[0],
                RANK=self.RANK,
                LR_MN=self.LR_MN,
                LR_READOUT=self.LR_READOUT,
                LR_INI=self.LR_INI,
                LR_UeqV=self.LR_UeqV,
                DEVICE=self.device,
                LR_TYPE=self.LR_TYPE,
                LR_N_SUPPORTS=self.LR_N_SUPPORTS,
                LR_SUPPORT_WEIGHTS=self.LR_SUPPORT_WEIGHTS,
                LR_BASIS_DIM=self.LR_BASIS_DIM,
                LR_TRAIN_BIASES=self.LR_TRAIN_BIASES,
                LR_READOUT_DIM=self.LR_READOUT_DIM,
                LR_INIT_GAUSSIAN_BASIS=self.LR_INIT_GAUSSIAN_BASIS,
            )
        else:
            self.low_rank = None

    def _init_stp_buffers(self) -> None:
        self.stp_block_index: list[tuple[int, int, int]] = []
        self.W_stp_blocks_base: list[torch.Tensor] = []

        if not self.IF_STP:
            self.J_STP_param = None
            return

        J_stp = torch.as_tensor(self.J_STP, device=self.device, dtype=torch.float32)
        if getattr(self, "TRAIN_J_STP", False):
            self.J_STP_param = nn.Parameter(J_stp)
        else:
            self.register_buffer("J_STP_param", J_stp)

        for post in range(self.N_POP):
            for pre in range(self.N_POP):
                idx = pre + post * self.N_POP
                if not self.IS_STP[idx]:
                    continue

                pre_slice = self.slices[pre]
                post_slice = self.slices[post]

                denom = torch.abs(torch.as_tensor(self.Jab[post, pre], device=self.device))
                block = self.W_rec_base[pre_slice, post_slice].clone() / denom
                self.stp_block_index.append((pre, post, idx))
                self.W_stp_blocks_base.append(block)

    def build_trainable_matrix(self) -> Optional[torch.Tensor]:
        if self.LR_TRAIN:
            return self.low_rank(self.LR_NORM)
        return self.W_train_dense

    def build_recurrent(self, W_train: Optional[torch.Tensor]) -> torch.Tensor:
        W_rec = self.W_rec_base.clone()

        if W_train is None:
            return W_rec

        if self.TRAIN_EI:
            if tuple(W_train.shape) != (self.N_NEURON, self.N_NEURON):
                raise ValueError(f"W_train shape {tuple(W_train.shape)} invalid for TRAIN_EI")

            W_eff = W_train
            for pop_idx in range(self.N_POP):
                W_eff = normalize_tensor(W_eff, pop_idx, self.slices, self.train_scale)

            W_rec = W_rec + self.train_mask * W_eff

            if self.CLAMP:
                for pop_idx in range(self.N_POP):
                    W_rec = clamp_tensor(W_rec.T, pop_idx, self.slices).T
        else:
            expected = (self.Na[0], self.Na[0])
            if tuple(W_train.shape) != expected:
                raise ValueError(f"W_train shape {tuple(W_train.shape)} != expected {expected}")

            ee = self.slices[0]
            W_rec[ee, ee] = W_rec[ee, ee] + self.GAIN * W_train / torch.sqrt(torch.as_tensor(self.Ka[0], device=self.device))

            if self.CLAMP:
                W_rec = clamp_tensor(W_rec.T, 0, self.slices).T

        return W_rec

    def build_stp(self, W_train: Optional[torch.Tensor]) -> Optional[list[torch.Tensor]]:
        if not self.IF_STP:
            return None

        W_stp: list[torch.Tensor] = []
        fix_scale = torch.sqrt(torch.as_tensor(self.Ka[0], device=self.device))

        for k, (pre, post, idx) in enumerate(self.stp_block_index):
            base_block = self.W_stp_blocks_base[k]

            if pre == 0 and post == 0 and W_train is not None and not self.TRAIN_EI:
                block = (
                    self.GAIN
                    * self.J_STP_param
                    * (base_block / fix_scale * (1.0 + W_train / self.train_scale[0]))
                )
                if self.CLAMP:
                    block = clamp_tensor(block, 0, self.slices)
            else:
                block = (
                    self.W_STP[idx]
                    * self.J_STP_param
                    * base_block
                    / torch.sqrt(torch.as_tensor(self.Ka[pre], device=self.device))
                )

            W_stp.append(block)

        return W_stp

    def expand_for_hebbian(self, W_rec: torch.Tensor, batch_size: int) -> torch.Tensor:
        if not self.IF_HEBB:
            return W_rec
        return W_rec.unsqueeze(0).repeat(batch_size, 1, 1)

    def build_all(self, batch_size: int) -> WeightOutputs:
        W_train = self.build_trainable_matrix()
        W_rec = self.build_recurrent(W_train)
        W_stp = self.build_stp(W_train)
        W_rec = self.expand_for_hebbian(W_rec, batch_size)
        return WeightOutputs(W_train=W_train, W_rec=W_rec, W_stp=W_stp)

    def get_readout(self) -> Optional[torch.Tensor]:
        return None if self.low_rank is None else self.low_rank.get_readout()

import torch
from torch import nn

from src.hebbian import Hebbian
from src.plasticity import Plasticity

class PlasticityManager(nn.Module):
    """
    Builds per-forward plasticity modules and applies Hebbian updates.
    """

    def __init__(self, cfg, W_rec_base: torch.Tensor, stp_block_index: list[tuple[int, int, int]]) -> None:
        super().__init__()
        self.cfg = cfg
        self.W_rec_base = W_rec_base
        self.stp_block_index = stp_block_index

        for k, v in vars(cfg).items():
            setattr(self, k, v)

        self.hebb = Hebbian(self.ETA, self.DT, self.HEBB_TYPE, self.HEBB_FRAC) if self.IF_HEBB else None

    def make_stp_modules(self, state: NetworkState, batch_size: int, reset: bool):
        if not self.IF_STP:
            return None

        stp_modules = []
        u_last = [] if reset else state.u_stp_last
        x_last = [] if reset else state.x_stp_last

        if not reset and (u_last is None or x_last is None):
            raise RuntimeError("STP state missing on restore path")

        for pre, post, idx in self.stp_block_index:
            mod = Plasticity(
                self.USE[idx],
                self.TAU_FAC[idx],
                self.TAU_REC[idx],
                self.DT,
                (batch_size, self.Na[pre]),
                STP_TYPE=self.STP_TYPE,
                IF_INIT=reset,
                device=self.device,
            )

            if reset:
                u_last.append(torch.zeros_like(mod.u_stp.detach()))
                x_last.append(torch.zeros_like(mod.x_stp.detach()))
            else:
                mod.u_stp = u_last[len(stp_modules)].detach()
                mod.x_stp = x_last[len(stp_modules)].detach()

            stp_modules.append(mod)

        state.u_stp_last = u_last
        state.x_stp_last = x_last
        return stp_modules

    def make_ff_stp_module(self, state: NetworkState, batch_size: int, reset: bool):
        if not self.IF_FF_STP:
            return None

        mod = Plasticity(
            self.FF_USE,
            self.TAU_FF_FAC,
            self.TAU_FF_REC,
            self.DT,
            (batch_size, self.N_NEURON),
            STP_TYPE=self.STP_TYPE,
            IF_INIT=reset,
            device=self.device,
        )

        if reset:
            state.u_ff_stp_last = torch.zeros_like(mod.u_stp)
            state.x_ff_stp_last = torch.zeros_like(mod.x_stp)
        else:
            if state.u_ff_stp_last is None or state.x_ff_stp_last is None:
                raise RuntimeError("FF-STP state missing on restore path")
            mod.u_stp = state.u_ff_stp_last
            mod.x_stp = state.x_ff_stp_last

        return mod

    def apply_hebbian(
        self,
        hebb_rates: torch.Tensor,
        rates: torch.Tensor,
        W_rec: torch.Tensor,
    ) -> tuple[torch.Tensor, torch.Tensor]:
        if not self.IF_HEBB:
            return W_rec, hebb_rates

        if W_rec.dim() != 3:
            raise ValueError(f"Hebbian path expects batched W_rec, got shape {tuple(W_rec.shape)}")
        if hebb_rates is None:
            raise RuntimeError("hebb_rates is None while IF_HEBB=True")

        for pre in range(self.N_POP):
            pre_rates = rates[:, self.slices[pre]]
            hebb_pre = hebb_rates[:, self.slices[pre]]

            for post in range(self.N_POP):
                idx = pre + post * self.N_POP
                if not self.IS_HEBB[idx]:
                    continue

                post_rates = rates[:, self.slices[post]]
                hebb_post = hebb_rates[:, self.slices[post]]

                W_hebb = self.hebb(pre_rates, post_rates, hebb_pre, hebb_post)
                W_hebb = W_hebb / torch.sqrt(torch.as_tensor(self.Ka[0], device=self.device))

                base = self.W_rec_base[self.slices[pre], self.slices[post]].unsqueeze(0)
                W_rec[:, self.slices[pre], self.slices[post]] = base + W_hebb

        W_rec[:, self.slices[0]] = W_rec[:, self.slices[0]].clamp(min=0.0)
        if self.N_POP > 1:
            W_rec[:, self.slices[1]] = W_rec[:, self.slices[1]].clamp(max=0.0)

        if self.HEBB_TYPE == "bcm":
            hebb_rates = hebb_rates * self.EXP_HEBB + rates * (1.0 - self.EXP_HEBB)

        return W_rec, hebb_rates

from __future__ import annotations

import torch
from torch import nn

from src.activation import Activation
from src.network_state import NetworkState
from src.network_weights import recurrent_matmul


class DynamicsCore(nn.Module):
    """
    One-step dynamics update.
    """

    def __init__(self, cfg, stp_block_index: list[tuple[int, int, int]]) -> None:
        super().__init__()
        self.cfg = cfg
        self.stp_block_index = stp_block_index
        self.activation = Activation()

        for k, v in vars(cfg).items():
            setattr(self, k, v)

        self.thresh_ff: torch.Tensor | None = None

    def reset_buffers(self, ff0: torch.Tensor | None = None) -> None:
        if self.IF_FF_ADAPT:
            if ff0 is None:
                raise ValueError("ff0 must be provided when IF_FF_ADAPT=True")
            self.thresh_ff = torch.zeros_like(ff0)

    def _compute_stp_hidden(
        self,
        rates: torch.Tensor,
        batch_size: int,
        stp_modules,
        W_stp,
    ) -> torch.Tensor | None:
        if not self.IF_STP or stp_modules is None or W_stp is None:
            return None

        hidden_stp_total = torch.zeros((batch_size, self.N_NEURON), device=self.device)

        for k, (pre, post, _) in enumerate(self.stp_block_index):
            aux = stp_modules[k](rates[:, self.slices[pre]])
            hidden_block = aux @ W_stp[k]
            hidden_stp_total[:, self.slices[post]] += hidden_block

        return hidden_stp_total

    def step(
        self,
        state: NetworkState,
        ff_step: torch.Tensor,
        W_rec: torch.Tensor,
        W_stp,
        stp_modules,
        ff_stp_module,
    ) -> NetworkState:
        rates = state.rates
        rec_input = state.rec_input
        thresh = state.thresh
        ff_prev = state.ff_prev

        if rates.dim() != 2:
            raise ValueError(f"rates must be 2D, got {tuple(rates.shape)}")
        if rec_input.dim() != 3:
            raise ValueError(f"rec_input must be 3D, got {tuple(rec_input.shape)}")
        if ff_step.shape[0] != rates.shape[0]:
            raise ValueError(f"ff_step batch mismatch: {tuple(ff_step.shape)} vs {tuple(rates.shape)}")

        batch_size = rates.shape[0]
        hidden = recurrent_matmul(rates, W_rec)

        hidden_stp_total = self._compute_stp_hidden(rates, batch_size, stp_modules, W_stp)
        if hidden_stp_total is not None:
            hidden = hidden + hidden_stp_total

        if self.IF_FF_STP and ff_stp_module is not None:
            k0 = torch.sqrt(torch.as_tensor(self.Ka[0], device=self.device))
            hidden_ff_stp = torch.sign(ff_step) * (ff_stp_module(torch.abs(ff_step) / k0) * k0)
            ff_step = ff_step + hidden_ff_stp

        if self.IF_FF_DYN:
            ff_step = ff_prev * self.EXP_FF + ff_step * (1.0 - self.EXP_FF)
            ff_prev = ff_step

        if self.IF_BATCH_J:
            hidden[:, self.slices[0]].add_(self.Jab_batch * rates[:, self.slices[0]] @ self.W_batch_T)

        if self.SYN_DYN:
            rec_input[0] = rec_input[0] * self.EXP_DT_TAU_SYN + hidden * (1.0 - self.EXP_DT_TAU_SYN)
        else:
            rec_input[0] = hidden

        if self.IF_FF_ADAPT:
            if self.thresh_ff is None:
                self.thresh_ff = torch.zeros_like(ff_step)

            ff_step = torch.sign(ff_step) * nn.ReLU()(ff_step - self.thresh_ff)
            self.thresh_ff = (
                self.thresh_ff * self.EXP_FF_ADAPT
                + nn.ReLU()(ff_step) * self.A_FF_ADAPT * (1.0 - self.EXP_FF_ADAPT)
            )

        net_input = ff_step + rec_input[0]

        if self.IF_NMDA:
            if W_rec.dim() == 2:
                hidden_nmda = recurrent_matmul(rates[:, self.slices[0]], W_rec[self.slices[0]])
            elif W_rec.dim() == 3:
                hidden_nmda = recurrent_matmul(rates[:, self.slices[0]], W_rec[:, self.slices[0]])
            else:
                raise ValueError(f"Invalid W_rec shape for NMDA path: {tuple(W_rec.shape)}")

            if hidden_stp_total is not None:
                hidden_nmda[:, self.slices[0]] += hidden_stp_total[:, self.slices[0]]

            rec_input[1] = (
                rec_input[1] * self.EXP_DT_TAU_NMDA
                + self.R_NMDA * hidden_nmda * (1.0 - self.EXP_DT_TAU_NMDA)
            )
            net_input = net_input + rec_input[1]

        non_linear = self.activation(net_input, func_name=self.TF_TYPE, thresh=thresh)

        if self.RATE_DYN:
            rates = rates * self.EXP_DT_TAU + non_linear * (1.0 - self.EXP_DT_TAU)
        else:
            rates = non_linear

        if self.IF_ADAPT:
            thresh[:, self.slices[0]] = (
                thresh[:, self.slices[0]] * self.EXP_ADAPT
                + rates[:, self.slices[0]].detach() * self.A_ADAPT * (1.0 - self.EXP_ADAPT)
            )

        state.rates = rates
        state.rec_input = rec_input
        state.thresh = thresh
        state.ff_prev = ff_prev
        return state

        self.mv_rec = 0

            rates=rates,
            rec_input=rec,
            stp_u=stp_u,
            stp_x=stp_x,

class StateManager:
    """
    Handles initialization, restoration, and persistence of transient network state.
    """

    def __init__(self, cfg, activation) -> None:
        self.cfg = cfg
        self.activation = activation

        for k, v in vars(cfg).items():
            setattr(self, k, v)

        self.rates_last: torch.Tensor | None = None
        self.rec_input_last: torch.Tensor | None = None
        self.thresh_last: torch.Tensor | None = None
        self.ff_prev_last: torch.Tensor | None = None
        self.hebb_rates_last: torch.Tensor | None = None
        self.end_mask: torch.Tensor | None = None

    def initialize(self, ff_input: torch.Tensor) -> NetworkState:
        if ff_input.dim() not in (2, 3):
            raise ValueError(f"ff_input must be 2D or 3D, got {tuple(ff_input.shape)}")

        batch_size = ff_input.shape[0]
        thresh = self.thresh[:batch_size].clone()

        rec_input = torch.randn(
            (self.IF_NMDA + 1, batch_size, self.N_NEURON),
            device=self.device,
        )

        ff0 = ff_input if self.LIVE_FF_UPDATE else ff_input[:, 0]
        rates = self.activation(ff0 + rec_input[0], func_name=self.TF_TYPE, thresh=thresh)
        hebb_rates = rates.clone() if self.IF_HEBB else None

        return NetworkState(
            rates=rates,
            rec_input=rec_input,
            thresh=thresh,
            ff_prev=torch.zeros_like(ff0),
            hebb_rates=hebb_rates,
        )

    def restore(self) -> NetworkState:
        if self.rates_last is None or self.rec_input_last is None or self.thresh_last is None or self.ff_prev_last is None:
            raise RuntimeError("No saved state available to restore")

        return NetworkState(
            rates=self.rates_last,
            rec_input=self.rec_input_last,
            thresh=self.thresh_last,
            ff_prev=self.ff_prev_last,
            hebb_rates=self.hebb_rates_last,
        )

    def init_last_state_buffers(self, state: NetworkState, batch_size: int) -> None:
        self.rates_last = torch.zeros_like(state.rates.detach())
        self.rec_input_last = torch.zeros_like(state.rec_input.detach())
        self.thresh_last = torch.zeros_like(state.thresh.detach())
        self.ff_prev_last = torch.zeros_like(state.ff_prev.detach())
        self.end_mask = torch.ones((batch_size, 1), device=self.device)

        if self.IF_HEBB and state.hebb_rates is not None:
            self.hebb_rates_last = torch.zeros_like(state.hebb_rates.detach())

    def maybe_save(self, step: int, state: NetworkState, end_indices, stp_modules=None, ff_stp_module=None) -> None:
        """
        Preserves legacy semantics. Revisit once end_indices shape semantics are clarified.
        """
        if self.end_mask is None:
            raise RuntimeError("Last-state buffers were not initialized")

        target = end_indices[-1]
        if not torch.any(step == target):
            return

        end_idx = torch.where(step == target)[0]

        self.end_mask[end_idx, 0] = float("nan")
        self.rates_last[end_idx] = state.rates[end_idx].detach()
        self.rec_input_last[:, end_idx] = state.rec_input[:, end_idx].detach()
        self.thresh_last[end_idx] = state.thresh[end_idx].detach()
        self.ff_prev_last[end_idx] = state.ff_prev[end_idx].detach()

        if self.IF_HEBB and state.hebb_rates is not None:
            self.hebb_rates_last[end_idx] = state.hebb_rates[end_idx].detach()

        if stp_modules is not None:
            if state.u_stp_last is None:
                state.u_stp_last = [torch.zeros_like(m.u_stp) for m in stp_modules]
                state.x_stp_last = [torch.zeros_like(m.x_stp) for m in stp_modules]
            for k, mod in enumerate(stp_modules):
                state.u_stp_last[k][end_idx] = mod.u_stp[end_idx].detach()
                state.x_stp_last[k][end_idx] = mod.x_stp[end_idx].detach()

        if ff_stp_module is not None:
            if state.u_ff_stp_last is None:
                state.u_ff_stp_last = torch.zeros_like(ff_stp_module.u_stp)
                state.x_ff_stp_last = torch.zeros_like(ff_stp_module.x_stp)

            state.x_ff_stp_last[end_idx] = ff_stp_module.x_stp[end_idx].detach()

        clear_cache()

    def _load_config(self, config) -> None:
        for key, value in vars(config).items():
            if hasattr(self, key):
                raise ValueError(f"Config key collision: {key}")
            setattr(self, key, value)

    def init_ff_input(self) -> torch.Tensor:
        return init_ff_input(self).to(self.device)

    def _prepare_ff_input(self, ff_input: torch.Tensor | None) -> torch.Tensor:
        if ff_input is None:
            ff_input = init_ff_input(self)
        ff_input = ff_input.to(self.device)

        if ff_input.dim() not in (2, 3):
            raise ValueError(f"ff_input must be 2D or 3D, got {tuple(ff_input.shape)}")
        return ff_input

    def forward(
        self,
        ff_input: torch.Tensor | None = None,
        RET_STP: int = 0,
        RET_REC: int = 0,
        IF_INIT: int = 1,
        return_outputs: bool = False,
    ) -> torch.Tensor | ForwardOutputs:
        ff_input = self._prepare_ff_input(ff_input)

        if IF_INIT:
            state = self.state_manager.initialize(ff_input)

            ff0 = ff_input if self.LIVE_FF_UPDATE else ff_input[:, 0]
            self.dynamics.reset_buffers(ff0=ff0)

            if self.TRAINING == 0:
                self.state_manager.init_last_state_buffers(state, ff_input.shape[0])
        else:
            state = self.state_manager.restore()

        batch_size = state.rates.shape[0]
        weights = self.weight_builder.build_all(batch_size=batch_size)

        stp_modules = self.plasticity_manager.make_stp_modules(
            state,
            batch_size=batch_size,
            reset=bool(IF_INIT),
        )
        ff_stp_module = self.plasticity_manager.make_ff_stp_module(
            state,
            batch_size=batch_size,
            reset=bool(IF_INIT),
        )

        if self.IF_OPTO and weights.W_stp is not None and len(weights.W_stp) > 0:
            rand_idx = torch.randperm(
                weights.W_stp[0].size(0),
                device=weights.W_stp[0].device,
            )[: self.N_OPTO]
            weights.W_stp[0][rand_idx] = 0

        collector = OutputCollector(
            self.config,
            return_rec=bool(RET_REC),
            return_stp=bool(RET_STP),
        )

        for step in range(self.N_STEPS):
            if self.IF_HEBB and step >= self.N_HEBB:
                weights.W_rec, state.hebb_rates = self.plasticity_manager.apply_hebbian(
                    state.hebb_rates,
                    state.rates,
                    weights.W_rec,
                )

            if self.RATE_NOISE:
                noise = torch.randn((batch_size, self.N_NEURON), device=self.device)
                state.rates = state.rates + noise * self.VAR_RATE

            ff_step = live_ff_input(self, step, ff_input) if self.LIVE_FF_UPDATE else ff_input[:, step]

            state = self.dynamics.step(
                state=state,
                ff_step=ff_step,
                W_rec=weights.W_rec,
                W_stp=weights.W_stp,
                stp_modules=stp_modules,
                ff_stp_module=ff_stp_module,
            )

            if self.TRAINING == 0:
                self.state_manager.maybe_save(
                    step,
                    state,
                    self.end_indices,
                    stp_modules=stp_modules,
                    ff_stp_module=ff_stp_module,
                )

            collector.update(step, state, stp_modules=stp_modules)

        rates = collector.stacked_rates()

        readout = None
        if self.LR_TRAIN:
            ro = self.weight_builder.get_readout()
            if ro is None:
                raise RuntimeError("LR_TRAIN=True but no low-rank readout available")
            readout = rates @ ro / self.Na[0]

        final = collector.finalize(readout=readout)

        self.rates_list = final.rates
        if final.rec_input is not None:
            self.rec_input = final.rec_input
        if final.stp_u is not None:
            self.u_list = final.stp_u
        if final.stp_x is not None:
            self.x_list = final.stp_x
        if final.readout is not None:
            self.readout = final.readout
        if self.IF_HEBB:
            self.W_hebb_T = weights.W_rec

        return final if return_outputs else final.rates
#+end_src

*** how do I use the new layout?

Use it like the old =Network=, but import paths and optional richer outputs change slightly.

**** 1. File layout

Put these files in =src/=:

- =network.py=
- =network_state.py=
- =network_weights.py=
- =network_plasticity.py=
- =network_dynamics.py=
- =network_outputs.py=
- =network_state_mgr.py=

Then keep your existing modules:
- =configuration.py=
- =activation.py=
- =plasticity.py=
- =hebbian.py=
- =ff_input.py=
- =lr_utils.py=
- =utils.py=
- =connectivity.py=

---

**** 2. Basic usage

Same as before:

#+begin_src python
from src.network import Network

net = Network(conf_name="my_config", repo_root="/path/to/NeuroFlame")
rates = net(ff_input)
#+end_src

Expected return:
- by default: =rates= only

Shape:
- usually =(N_BATCH, N_OUT_STEPS, N_E)= if you only emit pop 0 as in the original code

---

**** 3. With generated feedforward input

If you want the network to generate its own FF input:

#+begin_src python
rates = net()
#+end_src

Or explicitly:

#+begin_src python
ff_input = net.init_ff_input()
rates = net(ff_input)
#+end_src

---

**** 4. Request richer outputs

The new layout adds:

#+begin_src python
out = net(ff_input, RET_REC=1, RET_STP=1, return_outputs=True)
#+end_src

Then:

#+begin_src python
out.rates
out.rec_input
out.stp_u
out.stp_x
out.readout
#+end_src

So:

- =return_outputs=False=  -> returns only =rates=
- =return_outputs=True=   -> returns a =ForwardOutputs= dataclass

Example:

#+begin_src python
out = net(ff_input, RET_REC=1, return_outputs=True)
print(out.rates.shape)

if out.rec_input is not None:
    print(out.rec_input.shape)
#+end_src

---

**** 5. Stateful / continuation runs

Old behavior with =IF_INIT= is preserved.

Fresh state:
#+begin_src python
rates = net(ff_input, IF_INIT=1)
#+end_src

Resume from saved state:
#+begin_src python
rates = net(ff_input_next, IF_INIT=0)
#+end_src

Important:
- =IF_INIT= still means “initialize/reset transient dynamics”
- if =IF_INIT=0, the model expects previously saved state buffers to exist

---

**** 6. Training usage

Nothing special changes at call site:

#+begin_src python
net = Network(conf_name, repo_root)
optimizer = torch.optim.Adam(net.parameters(), lr=1e-3)

rates = net(ff_input)
loss = some_loss_fn(rates, target)

optimizer.zero_grad()
loss.backward()
optimizer.step()
#+end_src

If low-rank training is enabled, readout is still available after forward:

#+begin_src python
if hasattr(net, "readout"):
    y = net.readout
#+end_src

Or more cleanly:

#+begin_src python
out = net(ff_input, return_outputs=True)
if out.readout is not None:
    y = out.readout
#+end_src

- =net.weight_builder=

- =net.plasticity_manager=

#+begin_src python
print(net.weight_builder.W_rec_base.shape)
